# ADR 0004: ESM package and protected-tag release

Accepted. Build one neutral ESM entry and declarations using tsdown. A packed consumer and Expo/Metro smoke test guard exports. Changesets prepares reviewed versions and changelogs; a protected version tag is the only publish trigger. OIDC publishing runs only on GitHub-hosted runners. Pre-1.0 releases use the `next` dist-tag until mobile adapter verification is complete.
